# Editorial review — DESIGN.md and EXPERIENCE.md

Reviewed 2026-08-29. Lenses: structure, then prose. Reader type: llm (one human architect as secondary). Style guide: the project's own (sentence case, ISO dates, `H:MM:SS`, `api`, no exclamation marks, glossary terms). Content is sacrosanct; every row is a proposal the author accepts or rejects. No `[ASSUMPTION]` tag and no `{path.to.token}` reference is altered by any row.

## Purpose and audience read

These two files exist to let coding agents (and one architect) build stories 6.5, 6.6, 7.4, 8.3, 10.5, 10.6 and 10.7 with one look and one behavior without re-reading the sources — DESIGN.md answers "what does it look like", EXPERIENCE.md answers "what does it do, backed by which field". Anything a builder cannot act on, or could act on two ways, is a defect; restated source material (personas, FRs, scope) is bloat because the spines inherit sources by reference.

## Structure model per file

| File | Model | Fit |
|---|---|---|
| DESIGN.md | Reference/Database | Frontmatter tokens, a component catalog with a consistent schema (name → token → treatment), and a 97-row contrast table are random-access reference. Brand & Style and Colors are Explanation-shaped by the DESIGN.md spec; that is allowed and not scored as a mismatch. Judged on MECE and schema consistency. |
| EXPERIENCE.md | Reference/Database | IA, Component Patterns, State Patterns, Traceability and Requirement Map are lookup tables with a fixed schema. Two sections fight the model: Inspiration & Anti-patterns (Explanation, fully redundant with rules stated elsewhere) and Key Flows (Tutorial/Linear narrative). The mismatch is itself a finding (rows 11 and 12). |

## Closing summary

- **Total recommendations:** 30 table rows (8 structure, 22 prose) plus 13 minor.
- **Estimated reduction if all are accepted** (from `word_metrics.py` counts; frontmatter untouched):
  - DESIGN.md: about −275 words → 6,267 (−4.2% of total; −5.4% of the 5,130-word body). Rows 26, 27, 28, 6.
  - EXPERIENCE.md: about −515 words → 7,414 (−6.5%). Rows 11, 12, 13, 6, 28, 29 and the minor cuts, net of ~+50 words added by rows 9, 15, 19 and 24.
  - Combined: about −790 words, 14,471 → ~13,680 (−5.5%).
- **Length target:** none provided; not assessed.
- **Comprehension trade-offs:** row 12 removes the narrative arc from Key Flows, which served the human architect; the numbered steps keep every string and call. Row 27 removes the one-line rationale for each rejected color system; the `[ASSUMPTION]` tag and the linked studies keep the decision recoverable. Row 11 removes the "Lifted from / Rejected" index; each rule survives at its point of use, but a reader who wanted the list in one place loses it. Rows 9, 15, 19 and 24 add words: definitions and disambiguation rules that an llm reader needs before use.
- **What was not found:** no unresolved `{path.to.token}` reference in EXPERIENCE.md; no `[ASSUMPTION]` tag without a findings pointer; the contrast table's 97 rows and its AAA/AA/non-text summary are internally consistent; state names (`queued running done posted skipped failed unknown`; health `ok degraded invalid missing not-required stopped`; acquisition `queued | running | posted | failed`; stepper `launch running posted ingesting`) match across both files; the Add-meeting / Add meeting convention holds in 34 of 35 usages.
