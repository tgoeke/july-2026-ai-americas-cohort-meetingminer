Evidence Pipeline Today

  • Drop → probe → frames → OCR → screens → transcribe → align → moments → extract
  • Every stage checkpointed and idempotent; jobs resume, never rebuild
  • Deterministic components own capture, alignment, provenance, replay

Retrieval Split Graph and Document Index

  • Graph answers structural questions — screen history, who-heard-what
  • Document index answers wording — BM25 first, vectors for paraphrase
  • Both are rebuildable projections of the database of record

Nothing Enters a Store Before Approval

The publish gate

  • Extracted artifacts start unpublished — visible only in the moment view
  • A human gesture publishes; publishing re-indexes into both stores
  • Search can never surface unapproved AI output

Q4 Proposal and Open Risks

  • Retrieval eval with graded relevance, not spot checks
  • Augmentation intake for late-arriving recordings at scale
  • Risk: OCR anchors on low-bitrate screen shares
